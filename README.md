# POE2 Utilities

A collection of Path of Exile 2 utilities. https://poe2-utility.vercel.app

- **Exchange Rates**: Compare currency exchange rates side-by-side on a single screen
- **Tablets**: Generate regex for stash searches and check tablet modifier market prices
- **Crafting Guides**: Step-by-step crafting instructions for Full MF Rings and 5-Mod Jewels

Market data is provided by [poe.ninja](https://poe.ninja/poe2). The source updates roughly every hour, and this app caches it for 5 minutes.
